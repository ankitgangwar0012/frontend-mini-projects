# 🎨 Frontend Mini Projects

A curated collection of **small frontend projects** built using **HTML, CSS, and JavaScript**.  
This repository is created to practice UI design, animations, layouts, and core frontend concepts.

Each project is organized in its own folder with clean structure and live previews.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript

---

## 🎯 Goals of This Repository

- Improve frontend fundamentals
- Practice UI design and layouts
- Build a strong GitHub portfolio
- Create reusable UI components

---

## 📌 Notes

- All projects are **pure frontend** (no frameworks)
- Focused on **clarity, structure, and design**
- Ideal for beginners and practice reference

## 📂 Project Structure

Almost each project follows the same clean structure:

- project-name/
    - README.md
    - index.html
    - style.css
    - script.js (optional)
    - preview/
        - preview.png or preview.gif
    - assets/ (optional) 
        - (images/icons)
